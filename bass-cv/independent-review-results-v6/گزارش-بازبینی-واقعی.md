# گزارش پردازش پاسخ واقعی دو بازبین — Falmex v6

## وضعیت فایل‌ها

هر دو فایل ارسالی با موفقیت خوانده و پردازش شدند:

- بازبین A: آرشیو ZIP سالم، ۲۴ JSON و ۲۴ PNG؛
- بازبین B: آرشیو RAR5 سالم، ۲۴ JSON و ۲۴ PNG؛
- هر ۴۸ تصویر با هش منابع freeze‌شده مطابقت داشتند؛
- هیچ محتوایی از annotationها و فایل‌های اصلی ارسالی ویرایش نشد.

هویت، استقلال و تخصص بازبین‌ها از روی فایل قابل اثبات نیست. بنابراین این نتیجه «توافق بین دو مجموعهٔ annotation ارسالی» است، نه تأیید متخصص مستقل یا gold standard.

## نتیجهٔ توافق

| شاخص | نتیجه |
|---|---:|
| فریم مثبت در A | ۷ از ۲۴ |
| فریم مثبت در B | ۲۴ از ۲۴ |
| اختلاف مثبت/منفی | ۱۷ فریم |
| فریم منفیِ توافقی | ۰ |
| Macro IoU در فریم‌های positive-union | ۰٫۱۱۰۷۷۸ |
| Macro Dice در فریم‌های positive-union | ۰٫۱۵۵۵۹۱ |
| Micro IoU | ۰٫۲۵۷۳۳۷ |
| Micro Dice | ۰٫۴۰۹۳۳۷ |
| Macro boundary F1 با تلورانس دو پیکسل | ۰٫۱۱۴۵۱۱ |
| فریم دارای flag عدم‌قطعیت از حداقل یک بازبین | ۴ |
| فریم نیازمند داور سوم | ۲۴ |

بازبین B در ۱۷ فریمی که A منفی دانسته، نواحی مثبت کوچک ثبت کرده است. در هفت فریم مثبت مشترک نیز maskها تفاوت دارند. بررسی بصری overlayها نشانه‌ای از جابه‌جایی مختصات یا خطای rasterization نشان نداد؛ اختلاف در خود annotationها وجود دارد.

## تصمیم فنی

هیچ‌کدام از روش‌های union، intersection یا ترجیح خودکار یک بازبین برای ساختن consensus استفاده نشد. هر ۲۴ فریم وارد صف داوری شدند. بستهٔ داور سوم شامل منبع، قالب خالی، overlay اختلاف A/B و جدول صف است و هیچ prediction، نام مدل یا امتیاز مدلی در آن قرار ندارد.

متریک‌های freeze‌شدهٔ v6 و مرجع اولیهٔ source-only تغییر نکرده‌اند. هنوز ارزیابی مدل با مرجع داوری‌شده انجام نشده و ادعایی دربارهٔ اعتبارسنجی مستقل متخصص یا آمادگی عملیاتی وجود ندارد.

## قدم بعد

قالب‌های موجود در بستهٔ داور سوم باید توسط نفر سوم تکمیل شوند. برای فریم منفی، `shapes=[]` و `flags.no_visible_flame=true` لازم است. پس از دریافت پاسخ، مرجع نهایی با provenance مشخص freeze و ارزیابی مدل‌ها به‌صورت جداگانه و بدون تغییر نتایج اولیه انجام می‌شود.
