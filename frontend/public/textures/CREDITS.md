# Planet textures (NASA, public domain)

- earth.webp — NASA Visible Earth, Blue Marble: Land Surface, Shallow Water, and Shaded Topography
  (https://visibleearth.nasa.gov/images/57752)
- moon.webp — NASA Scientific Visualization Studio, CGI Moon Kit, LRO LROC color map
  (https://svs.gsfc.nasa.gov/4720)
- mars.webp — NASA 3D Resources, Mars (Viking-based global color map)
  (https://github.com/nasa/NASA-3D-Resources)

NASA imagery is generally not subject to copyright in the United States. Use of these images
does not imply NASA endorsement.

## Added for the WebGL planets

- earth-night, earth-clouds, earth-normal, earth-specular (.webp) — Solar System Scope
  (https://www.solarsystemscope.com/textures/), based on NASA imagery, licensed CC BY 4.0.
- moon-height.webp — NASA Scientific Visualization Studio, CGI Moon Kit, LOLA elevation
  (https://svs.gsfc.nasa.gov/4720)

The .webp files are re-encoded copies of the maps above, for faster loading.
